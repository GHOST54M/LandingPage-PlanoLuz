# LandingPage-PlanoLuz

Nesse projeto eu prototipei o desing e desenvolvi uma landing page para a empresa Plano Luz.

---

## 🚨 Problema

A empresa solicitou o desenvolvimento de uma Landing Page para impulsionar o marketing para o seu aplicativo.
Também foi solicitado que a página colete dados de comportamento do usuário permitindo a rastreabilidade do comportamento para permitir tomadas de decisões e otimizações futuras

---

## 💡 Solução Proposta

Desenvolvimento de uma página web que permite a divulgação em larga escalada do produto, com integração de ferramentas de análise como o Google Analytics e Meta Pixel

---

## 🚀 Funcionalidades

Botões de levam à página de download do app na APP Store e Google Play
Coleta e envio de dados para o google analytics e o Meta pixel
Desing responsivo para todas os tamanhos de tela

---

## 🛠️ Tecnologias Utilizadas

### Frontend
- HTML
- CSS
- JavaScript

### Serviços externos
- Google Tag Manager
- Google Analytics
- Meta Pixel
